# Features

What Checkmage does in the Discord server it is invited to. There is no
tier gate: it answers anyone who can see the channel.

## AI persona replies

**What it does.** Mentioning the bot (`@Checkmage`) gets a reply from
"Checkmage," a scholarly-wizard persona with a fixed system prompt,
generated by an LLM call through Groq's API (`llama3-70b-8192`).

**How to use it.** `@`-mention the bot anywhere in a message it can see.

**What it does not do.** The persona and its prompt are fixed in code —
there is no per-server or per-user customization, and no memory between
messages.

## Dice roller

**What it does.** `!roll` parses dice-notation expressions
(`NdM±K` or `NdM±PdQ`), rolls them, sums the result, and flags a critical
success or failure when the total equals the maximum or minimum possible
roll on an expression difficult enough to matter.

**How to use it.** `!roll 2d6+1d4` (or any similar expression) in a
channel the bot can see.

**What it does not do.** It does not track characters or campaigns —
each roll is a one-off, stateless calculation.

## Weekly session announcer

**What it does.** `!thursday` or `!friday` posts the next session's start
and end time as a Discord countdown timestamp, incrementing the session
number it finds in the channel's recent history (or starting at 13 if it
finds none), then deletes the triggering command.

**How to use it.** Type `!thursday` or `!friday` in the session-planning
channel.

**What it does not do.** It reads only the most recent 50 messages for a
session number, so a long gap in posting resets the count rather than
continuing it.

## Trivia stats

**What it does.** Is meant to tally correct answers per player from a
separate trivia bot's messages in the channel and report accuracy
percentages.

**How to use it.** `!triviastats` in a channel the trivia bot has posted
in.

**What it does not do.** It never actually posts its result: the command
deletes the triggering message and then only logs the stats to the
bot's own console, never to the channel (`bot.mjs`, the commented-out
`channel.send(statsMessage)` in `calculateTriviaStats`) — see the open
bug noted in [contributing.md](contributing.md).

## Silly text mangler

**What it does.** For one Discord user, configured by ID in an
environment variable, a message ending in `?` or `!` gets edited to
prefix the matching inverted mark (`¿` or `¡`).

**How to use it.** Nothing to do — it is automatic, and only for that one
configured user.

**What it does not do.** It is not configurable per-server; the target
user is a single bot-wide ID.

## Trivia

`!fetch` is a sixth, smaller command: it calls a third-party hosted
table and posts one field back, left over from an early experiment
(`d3b24a2`).
